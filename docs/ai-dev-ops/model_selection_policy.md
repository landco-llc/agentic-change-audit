Standard is the requested/default speed. `.codex/config.toml` sets the default
Child to Sol/medium and a concurrency ceiling of four; it does not configure
the Parent. `.codex/agents/` defines execution profiles; `.agents/skills/`
defines procedures. A profile supplies no scope, risk acceptance, protected
effect, Ready, merge or Human Gate authority. Publication uses a separately
bound mechanical Luna/medium route for exact authorized public-safe bytes;
it adds no publication, Parent or Astra profile.

After applicable accepted project adoption, Parent defaults to `gpt-6.1-sol` /
low / Standard. A named material Parent control judgment may temporarily use
medium; a named complex control judgment may temporarily use high. Record
the reason, authority/target identity, prior/selected route, start, decision
boundary and handback. Return to low when resolved or handed to a Child at a
new launch, supported re-entry or natural safe boundary. Record pending
handback if the host cannot safely change the bound execution; infer no hot
switch, persistence, wake or scheduler capability. A critical Child does not
escalate Parent reasoning. Parent remains control-plane only: tests, task
execution and substantive artifact materialization/publication belong to
appropriately bound Children/workers.

Normal new Work uses GPT-6 or newer. GPT-5.6 is restricted to frozen legacy
execution, exact historical reproduction/compatibility evidence, or an
explicit exact current Work/Human exception after proving no adequate GPT-6+
route and preserving assurance. Cost, convenience, generic fallback or
unavailability alone is insufficient. An adequate GPT-6 fallback needs exact
current authority and role/risk/effort floors; no generic fallback mapping is
added. The expired temporary GPT-6 override and stale ACA GPT-5.6 table are
historical sources only. Astra remains conditional on current AFRONT
prerequisites and separately applicable authority; this Work enables none.
