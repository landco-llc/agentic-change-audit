# ACA local model-selection addendum

This public-safe addendum records ACA's active local reference to
accepted/current central routing semantics for bounded Work. Only
accepted/current authority may constrain or authorize routing. Candidate,
proposed, shadow, successor, experimental, or otherwise non-active material is
not executable authority. In particular, non-active Astra material cannot
select a model, expand Parent powers, continue a campaign, establish Fast Track
eligibility, or authorize Ready/merge. This addendum does not activate,
replace, or make a claim about the lifecycle status of any central source.

| Profile | Model / reasoning | Sandbox | ACA use |
| --- | --- | --- | --- |
| `reconciliation` | `gpt-5.6-luna` / `low` | `workspace-write` | deterministic evidence reconciliation |
| `implementation_mechanical` | `gpt-5.6-luna` / `medium` | `workspace-write` | exact mechanical changes |
| `implementation_standard` | `gpt-5.6-luna` / `medium` | `workspace-write` | bounded standard implementation |
| `implementation_backend` | `gpt-5.6-terra` / `medium` | `workspace-write` | backend or integration implementation |
| `architecture` | `gpt-5.6-terra` / `high` | `read-only` | architecture and boundary analysis |
| `audit_standard` | `gpt-5.6-terra` / `medium` | `read-only` | independent fixed-head audit |
| `implementation_critical` | `gpt-5.6-sol` / `high` | `workspace-write` | critical implementation |
| `audit_critical` | `gpt-5.6-sol` / `high` | `read-only` | critical independent audit |

The Parent selects the smallest profile consistent with the work record,
scope, risk, and escalation criteria. A profile must not widen scope or merge,
release, deployment, provider, or Human Gate authority. Audit and correction
remain separate contexts; a changed head requires a fresh independent re-audit.

For a named complex controller judgment only, the Parent may temporarily use a
stronger model/reasoning pair when that exact pair is both permitted by
applicable accepted/current Development Governance and represented in the
active ACA table above. The public-safe control record must state the prior
Parent route, temporary escalated route, accepted/current authority reference,
bounded reason and decision boundary, start point, and explicit de-escalation
point. De-escalate immediately when the judgment is resolved or handed to a
Child; routine routing, byte-exact transport, evidence-presence checks, and
state transitions do not retain the stronger route. If accepted/current
authority cannot be verified, remain on the ordinary Parent route or stop
fail-closed.

Temporary escalation never grants substantive authoring, implementation,
correction, audit/re-audit, scope expansion, risk acceptance, Ready/merge,
Human Gate, release, or protected-external authority. No new model/profile
pairing may be added from candidate/shadow material. Non-active Astra material
is not introduced or activated by this Work.
